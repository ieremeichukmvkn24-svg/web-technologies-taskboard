## Запуск

Відкрий `index.html` через Live Server у VS Code. Для Python-практичних запусти `python main.py` у відповідній папці.

## Перевірка

```bash
node --check js/app.js
python scripts/verify_site.py
python -m unittest discover -s practice1_input_conditions
python -m unittest discover -s practice2_while_list
python -m unittest discover -s practice3_for_dict
python -m unittest discover -s practice4_def
```

Всі 19 Python-тестів і статичні перевірки HTML/JavaScript пройшли локально. Це не означає автоматичного проходження всіх критеріїв викладача.
