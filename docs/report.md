## Практична №8 — HTML / методичка W-07

**Мета:** застосовувати семантичну розмітку HTML, створити дві взаємопов’язані сторінки.

**Виконання:** створив `index.html` і `about.html` із `<!DOCTYPE html>`, `<html lang="uk">`, `meta charset` і `viewport`, спільними шапкою та підвалом. На сторінці автора є картка профілю з `figure`, `figcaption`, список навичок, таблиця плану навчання з `thead`/`tbody`, контакти, зовнішнє посилання з `target="_blank"` і `rel="noopener noreferrer"`. Додав якорі `#skills`, `#plan`, `#contacts`, блок `details/summary` та сторінку `docs/links.html`.

**W-07: три речення про семантику.** Семантична розмітка описує призначення елементів сторінки, а не лише їх зовнішній вигляд. На відміну від великої кількості неінформативних `div`, теги `header`, `nav`, `main`, `section`, `article`, `footer` роблять структуру зрозумілішою для браузера, пошукових систем та допоміжних технологій. Семантика покращує доступність сайту й полегшує підтримку коду.

**Застосовані теги:** `html`, `head`, `meta`, `title`, `body`, `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `h1`, `h2`, `h3`, `p`, `a`, `strong`, `em`, `figure`, `img`, `figcaption`, `ul`, `li`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `details`, `summary`, `form`, `input`, `select`, `button`, `dialog`.

**Висновок:** я навчився застосовувати семантичні HTML-теги, пов’язувати сторінки навігацією, створювати таблиці й правильно додавати зображення.

## Практична №9 — CSS

**Мета:** застосувати CSS для оформлення сторінок і адаптивної верстки.

**Виконання:** створив `css/style.css`. Використав CSS-змінні, Grid для колонок TaskBoard та інформаційних карток, Flexbox для навігації, стани `:hover` і `:focus-visible`, `@media` для адаптації на мобільних пристроях.

**Результат:** оформлена дошка із трьома колонками на широких екранах та однією колонкою на вузьких екранах.

**Висновок:** я навчився керувати виглядом сайту за допомогою CSS і забезпечувати його читабельність на різних розмірах екрана.

## Практична №10 — TaskBoard оживає: JavaScript

**Мета:** додати інтерактивність та роботу з даними на клієнті.

**Виконання:** створив `js/app.js`. Реалізував додавання, редагування й видалення задач; поля назви, опису, дедлайну, пріоритету та статусу; фільтрацію, пошук, підрахунок показників, збереження даних у `localStorage` та Drag & Drop для зміни статусу.

**Результат:** дошка оновлюється без перезавантаження; після перезавантаження збережені завдання залишаються у браузері.

**Висновок:** я навчився працювати з DOM, обробляти події, використовувати масиви й об’єкти та зберігати дані за допомогою `localStorage`.

## Інструкція демонстрації

1. Відкрити `index.html` через Live Server у VS Code.
2. Перейти на `about.html`, перевірити зображення, список, таблицю, якорі та контакти.
3. Додати завдання, змінити пріоритет і статус, зберегти.
4. Знайти його через пошук і перевірити фільтр.
5. Перемістити картку у «Готово» й перевірити лічильники.
6. Перезавантажити сторінку й перевірити збережені дані.
7. Відкрити DevTools → Elements / Network, перевірити шляхи й помилки.
8. У терміналі виконати `git log --oneline --graph` для демонстрації історії.
