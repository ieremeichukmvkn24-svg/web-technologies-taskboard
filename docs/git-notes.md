# Приклади команд і звіт про Git

Гілку `html-pages` було створено локально, у ній додано сторінку автора, після чого зміни об'єднано з `main` через merge commit. В історії архіву можна подивитись злиття через `git log --oneline --graph --all`.

Для практичної 6: `git status` показує різницю між робочою директорією, індексом і останнім комітом. Після `git add` зміни потрапляють до індексу (staging area) і очікують commit. `git diff` показує незаписані зміни файлів, а `git diff --cached` — уже додані до індексу. `git switch main` перемикає поточну гілку, тоді як `git merge html-pages` переносить історію змін іншої гілки у поточну.

Якщо ті самі рядки змінити незалежно у двох гілках, Git може повідомити про конфлікт. Його розв'язують редагуванням файлу й завершенням merge через `git add` та `git commit`. У цьому архіві **немає штучно зробленого конфлікту**: для його демонстрації виконай вправу з відповідної методички.

Після створення репозиторію на GitHub треба додати віддалений `origin`, запушити `main`, за потреби створити окрему гілку, push і Pull Request. **У GitHub цей проєкт ще не завантажено**.
